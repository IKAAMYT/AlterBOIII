⚠️ Ce merge remplace BEAUCOUP de fichiers. La méthode la plus sûre :

MÉTHODE RECOMMANDÉE (branche de test) :
  1. Sur GitHub, crée une nouvelle BRANCHE (ex: "merge-ezz-juillet")
     depuis ta branche main.
  2. Dézippe ce ZIP sur ton PC.
  3. Upload/remplace les dossiers src/ et data/ + premake5.lua
     dans cette nouvelle branche (via GitHub web ou GitHub Desktop).
  4. Lance le workflow de build SUR CETTE BRANCHE.
  5. Si le build est VERT et que le jeu marche → merge la branche
     dans main.
  6. Si le build ÉCHOUE → tu n'as rien cassé sur main, on debug la
     branche ensemble.

  Ne remplace PAS directement main : si une erreur de compilation
  passe (impossible à tester en local), tu casserais ta version live.

CE QUI N'EST PAS DANS LE ZIP (à ne pas toucher) :
  • deps/ (submodules Git : Steamworks, curl, imgui... se récupèrent
    automatiquement via git submodule, déjà configurés)
  • old-dll/ (vieux binaires, inutiles au build)
  • .git/ (historique)
